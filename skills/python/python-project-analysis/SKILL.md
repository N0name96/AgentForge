# Python Project Analysis

Before significant work on an unfamiliar repository, inspect:

1. Project structure.
2. pyproject.toml / requirements files.
3. README and documentation.
4. Application entry points.
5. Source directories.
6. Test directories.
7. Frameworks used.
8. Architecture patterns.
9. Configuration.
10. CI configuration when relevant.

Identify:

- Python version
- package manager
- framework
- testing framework
- linting
- formatting
- type checking
- project architecture
- important modules
- external dependencies

Do not inspect every file blindly.

Start broad and progressively narrow the context toward files relevant to the task.
